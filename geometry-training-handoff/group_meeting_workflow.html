三视图 → 参数化程序 → STEP

TAIL · VALIDATOR

两个验收维度，输出一组结果

不是只比较工艺文本，而是同时检查工艺执行后的几何和工艺方案本身。

几何维度：逐工序重建、最终 STEP、关键尺寸、特征与表面距离。
工艺维度：工序依赖、装夹基准、设备刀具、公差能力与效率。
输出：几何分数、工艺分数、硬约束状态和可定位的失败原因。
THE CONTRACT BETWEEN THREE MODULES

三个模块必须通过结构化对象连接

GeometryBundle 固定头部输出，ProcessPlan 固定中间交付物，ValidationResult 固定尾部反馈。只有接口稳定，数据才能跨版本复用。

06 · Implementation order

实施顺序与训练顺序保持一致

先解决“输入是什么”和“什么算好”，再解决“怎样做得更好”。

PHASE 1 · NOW

建立并冻结头尾

完成几何提取器、工艺执行器与双维验收器，版本化接口和阈值。

得到：可信输入 X + 可信目标 R
PHASE 2

让数据进入循环

对每条样本运行候选 Workflow，保存完整 Rollout、奖励和失败原因。

得到：可训练的数据集 D
PHASE 3

优化中间 Workflow

搜索 Agent 数量、拓扑、模型、Prompt 与工具，并用固定验收器持续选择。

得到：更优的 Workflow θ*
